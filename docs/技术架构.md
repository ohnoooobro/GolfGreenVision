# 技术架构

## 当前建议
第一阶段采用静态移动 Web 应用：

- Vite + React + TypeScript
- 浏览器 Geolocation API
- `src/location` 提供真实定位与桌面模拟定位的统一接口，页面只消费 `LocationState`
- GeoJSON 表达球场地理数据
- 本地存储保存测试会话
- SVG 实现果岭可视化
- Vitest 覆盖核心计算逻辑

## 原则
- 能前端完成的 PoC 能力先不增加后端。
- 地理计算与 UI 尽量解耦。
- 真实 GPS 与桌面模拟定位使用统一的数据接口。
- 真实球场数据与演示数据必须能明显区分。
- 保持结构清晰，但不要为未来可能出现的问题提前过度抽象。
