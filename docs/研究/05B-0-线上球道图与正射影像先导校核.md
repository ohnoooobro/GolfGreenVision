## 比较方法与可重复性

先读线上地物组合，再在完整正射预览及未编号候选中查找对应区域；H12不依赖不存在的现场采样或邻洞顺序倒推。H13/H17随后对照05A私有GPS叠加和候选。对每个候选分别检查Tee→Green连接、打球方向左右关系、水面、沙坑组合及长度数量级，不以长度或单个沙坑纹理定洞。

本轮人工在源分辨率影像中读出可能梯台区域，按影像像素尺度计算其至既有Green候选中心的直线距离。读图点约±20像素（约5米）的选择余量，只是操作估计，不是统计误差或绝对精度保证；没有分配梯台颜色，也不是实测Tee中心。直线距离不等于标牌测距、实际击球路径或当日旗杆距离。候选中心本身也未经现场中心测量。

私有`field-tests/private/derived/05B-0/`保存本地影像裁剪、人工像素读数、量测脚本及`measurement_audit.json`，后者记录输入SHA-256、量测方法和限制。原始05A两份导出哈希与05A来源清单一致；未修改、删除或重标任何原始记录。第三方图仅在线查看，未保存进该目录或仓库。本轮是三洞视觉筛查，**不是盲测、全场穷举或成功率测量**；以下“主要候选数”仅适用于本轮所见区域。

## 是否扩大与05B.1建议

1. **方法有效吗？** 对本轮三洞的候选筛查有效，显著地物组合比仅Par/码数排序更有区分力；没有盲测或已确认洞号真值，不能计算成功率或承诺18洞自动识别。
2. **H12无GPS找到候选吗？** 是，G04与西南岸梯台群是主要合理候选；G13弱替代保留，尚未确认。
3. **H13缩小排查范围吗？** 是，先核实G06所对应真实H13布局及切换/迟采，再查定位问题；仍保留439米冲突和两处原始记录。
4. **H17有独立支持吗？** 有限支持TZ01/G23，但尚无官方/现场号牌确认，也不把重复定位当独立验证。
5. **值得扩展18洞吗？** 值得作为后续人工辅助审核，**当前先停在三洞**。建议05B.1先接收10月11日定向补证，闭合这三洞的洞号与年代链条，再由用户决定剩余洞研究范围；不直接启动全场数字化、发布或正式数据更新。若号牌/布局与三洞形态矛盾或无法解释版本差异，应暂停扩大并向场方核对。
