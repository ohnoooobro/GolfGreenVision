# 手机出发前验收

1. 在有网络时打开部署的 HTTPS URL，允许浏览器使用定位。
2. 打开“测试准备检查”，确认 HTTPS、安全上下文、定位权限、GPS、本地存储和 JSON 导出没有失败项；候选数据允许显示警告。
3. 点击“开始现场测试”，确认页面显示 Session 和“真实定位”，不要使用模拟定位。
4. 选择当前实际 Hole，记录一次“到达发球台”和一次“到达果岭”。
5. 刷新页面，点击“恢复未完成测试”，确认 Session、样本和轨迹仍在。
6. 点击“结束现场测试”，再点击“导出现场数据”。结束不会删除本地数据。
7. 在手机“文件”或分享界面确认 JSON 已保存；文件名类似 `jingshanhu-field-YYYY-MM-DD.json`。
8. 确认文件存在后，才点击“确认已保存后清除”。

网络短暂中断时，已打开页面中的 Session、Tee、Green、轨迹、确认事件和 JSON 导出继续使用本机 localStorage；首次打开页面仍需要网络。
