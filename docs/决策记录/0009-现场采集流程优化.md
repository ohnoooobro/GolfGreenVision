# 0009｜现场采集流程优化

日期：2026-10-08

## 决策

现场主流程固定为：选择实际 Hole → 选择本洞 T 台 → 记录 Tee → 记录 Green → 下一洞。每洞的 T 台类别独立保存，支持黑、金、蓝、白、红、其他和不确定。进入下一洞时可以继承上一洞类别，但继承值标记为未确认；它只作为便捷默认值，不能当作现场明确确认。

Tee 类别和 GPS 位置分别记录。Tee / Green 样本继续保存 WGS84 坐标、浏览器 accuracy、时间和原有预测上下文；样本增加 `teeCategory` 与 `teeSelectionStatus`。类别未知时照样允许采集，写入 `unknown`，不编造官方码数或 Tee 坐标。

页面把候选洞号和排序分收进调试区，主区域只显示实际洞号、T 台、Tee/Green 状态和 GPS 精度。上一洞、下一洞、18 洞快速选择、一键采样、撤销和导出均保留。漏采不阻塞下一洞，也不允许用之后地点的 GPS 追填旧洞；进度分别统计 Tee、Green、完整洞和漏采洞。

## 兼容与恢复

原有 localStorage 键 `golf-green-vision.field-test.v1`、Session、样本、轨迹和导出顶层结构继续有效。旧样本缺少 T 台字段时读取为 `unknown`；旧导出可通过读取函数校验后补齐缺省字段。升级写入前原文保存到带 Session 标识的备份键，避免静默覆盖历史数据。清除按钮仍要求用户先完成导出确认。

## 范围

本轮只优化现场采集交互和数据结构，不改净山湖 GIS、候选匹配、正射影像、记分卡隔离或 Pages 部署架构。
