# 0001｜项目初始化

## 决策

Thread 00 采用 Vite + React + TypeScript 作为前端基础，使用 Vitest 配合 React Testing Library 做组件测试。该组合启动快、类型检查明确、适合当前静态 Web PoC，并保留后续接入浏览器能力的空间。

## 本轮增加

- 运行时依赖：`react`、`react-dom`
- 开发依赖：`vite`、`@vitejs/plugin-react`、`typescript`、`vitest`、`jsdom`、`@types/react`、`@types/react-dom`、`@testing-library/react`、`@testing-library/jest-dom`
- 增加 Vite 入口、React 首页占位组件、基础样式、Vitest 配置和首页测试。

## 暂不引入

本轮没有引入地图、GPS、球场数据、后端、登录、状态管理或 UI 组件库。Thread 00 只验证工程能够启动、测试和构建，避免在业务边界尚未确认时增加复杂度。
