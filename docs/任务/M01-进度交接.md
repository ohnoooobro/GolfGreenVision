## 初步有价值发现（均不是最终结论）

1. **商业结构化数据确实存在公开供应信号。** Golf API 官方页面同时给出 REST、CSV、逐洞坐标和商业使用描述，说明“按 API/数据库订阅导入”在技术形态上可行；但价格、中国覆盖和再分发限制仍是决策阻塞项。
2. **成熟产品的展示能力不能反推可采购性。** Golfshot 公开展示全球 GPS、障碍物/目标距离和果岭图能力，但首页没有披露底层供应商或第三方授权入口；GolfLive 当前可见页面集中在赛事和记分。
3. **影像和结构化地图是两种不同资产。** 净山湖已有高分辨率正射影像，但 05A 与 OSM 结果共同表明：影像像素、未编号的 Green/Tee 面和真实 1-18 洞语义之间仍缺独立证据链。
4. **对中国球场，覆盖验证比供应商名单更关键。** 目前没有证据证明 Golf API、Golfshot、VOOGOLF 或其他候选对净山湖/中国球场提供可直接授权的完整 Tee/Green/障碍物数据；需用真实球场名称做小规模命中测试，并取得书面许可条款。
5. **05B 不应等待不确定外部数据。** 这是基于 05A 本地证据的工作假设：外部数据供应尚未证实，净山湖的人工审核仍是最低成本的可控路径；正式建议要等 M01 报告完成后再定稿。
