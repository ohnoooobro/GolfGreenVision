# Thread 00｜项目初始化

这是本项目第一次 Codex 开发任务。

## 本轮目标
只建立一个干净、可运行、可测试的工程基础。

不要提前实现业务功能。

## 请完成
1. 检查当前仓库结构，并保留现有 `AGENTS.md`、`docs/`、`data/`、`field-tests/`。
2. 如果当前目录还不是 Git 仓库，初始化 Git。
3. 在当前仓库中建立 Vite + React + TypeScript 项目。
   - 如果脚手架因为目录非空而拒绝初始化，可以先在临时目录创建，再谨慎合并到当前仓库。
   - 不要覆盖现有项目管理文件。
4. 配置 Vitest。
5. 建立清晰但不过度复杂的 `src/` 与 `tests/` 基础结构。
6. 首页只做一个简洁的移动端占位页面，显示：
   - `Golf Green Vision`
   - `现场测试原型`
   - `工程状态：Ready`
7. 页面以中文为主，移动端优先，高对比度，暂时不要追求复杂视觉效果。
8. 更新 `README.md`，补充：
   - 安装依赖
   - 启动开发服务器
   - 运行测试
   - 生产构建
9. 创建 `docs/决策记录/0001-项目初始化.md`，用中文简要记录：
   - 为什么选择当前基础技术栈
   - 本轮实际增加了哪些依赖
   - 暂时没有引入哪些东西，以及原因

## 本轮禁止提前实现
不要实现：

- GPS
- 地图
- 球场数据
- 自动识别洞号
- 距离计算
- 轨迹记录
- 果岭坡度
- 推杆线路
- 后端
- 登录系统

## 完成条件
结束前必须：

1. 运行测试；
2. 运行生产构建；
3. 修复本轮导致的失败；
4. 确认开发服务器可以正常启动；
5. 用中文给出简短总结。

总结应包含：

- 做了什么
- 修改/新增了哪些关键文件
- 测试是否通过
- 构建是否通过
- 是否有尚未解决的问题
- 下一步建议是什么

本轮完成后停止，不要自行进入 Thread 01。
