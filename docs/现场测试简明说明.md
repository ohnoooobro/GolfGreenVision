# 净山湖现场测试简明说明

## 第一次怎么测？

1. 打开页面后允许“位置”权限，点击“测试准备检查”。
2. 到球场后点击“开始现场测试”。
3. 每洞按顺序选择实际 Hole，再选择本洞 T 台：黑、金、蓝、白、红、其他或不确定。
4. 到发球台附近点一次“到达发球台”，到果岭附近点一次“到达果岭”。
5. 点“下一洞”继续。上一洞 T 台可能会作为未确认的默认值，随时可以修改。
6. 只打部分洞、只记录 Tee 或只记录 Green 都可以；不要离开后用别处位置补填旧洞。
7. 页面会分别显示已记录 Tee、Green 和漏采洞，可随时导出，结束后仍可导出。
8. 打完后先点“结束现场测试”，确认 JSON 已保存，再点“确认已保存后清除”。

**不要为了配合软件改变正常打球路线。**

**确认导出文件已经保存后，再清除本机测试数据。**
